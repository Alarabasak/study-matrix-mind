# ArrowCrossWordTYT

A mobile game like arrow crossword specifically for senior high school students and people who are willing to study to college entrance exam. Data sets for each course category will be given. The algorithm creates 12x12 , 16x12 , 12x16 sized matrices. The gaming environment should be unique, fun and not eye-tiring.
